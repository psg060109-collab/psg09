# 기획서 — 「불판 대첩」

> 동아리 부스용 먹기 대결 게임. **1인 vs 컴퓨터(CPU)**, 키보드 하나, 한 판은 최대 약 7분.
> 배포: GitHub Pages (정적 파일만, 서버 없음)

## 0. 한 줄 요약
고깃집 식탁을 위에서 내려다본 화면. 플레이어와 CPU가 마주 앉아 **공용 접시와 공용 불판**에서 음식을 먼저 집어 먹으며 **단백질·탄수화물·비타민** 세 수치를 지킨다.
**세 수치 중 하나라도 먼저 0이 되는 사람이 패배**한다. 수치는 시간이 갈수록 빨리 줄어들어 7분 안에 반드시 승부가 난다.
익자마자 먹는 **PERFECT**, 가끔 나오는 **황금 고기** 쟁탈, 상대를 묶는 **청양고추**가 직접 부딪히는 경쟁을 만든다.

### 확정된 결정 사항
| 항목 | 결정 |
|---|---|
| 경쟁 방식 | **1인 vs CPU** (쉬움·보통·어려움). 한 키보드 2인 대전은 자리가 좁고 고스팅 문제로 제외 |
| 조작 | `Q W E R` 접시(먹기·올리기), **Shift+QWER / Shift+UIOP = 불판 윗줄 / 아랫줄 칸 먹기** |
| 식탁 | 접시·불판 **전부 공용** (상대가 구운 고기를 빼앗아 먹을 수 있음) |
| 화면 | **탑뷰 식탁**, 플레이어 왼쪽·CPU 오른쪽 대면, 가운데 **사각 불판**, 캐릭터 이미지 없음 |
| 수치 | 3종: 단백질 / 탄수화물 / 비타민 (최대 100, 넘는 양은 버려짐) |
| 굽기 | 덜익음 → 익음 → 탐 (탄 건 2초 뒤 저절로 치워짐) |
| 불판 | 음식 8개까지 (2줄 × 4자리) |
| 경쟁 요소 | PERFECT 타이밍 · 황금 고기 · 청양고추 · 헛손질 페널티 |
| 피버 타임 | 무작위로 발생, 8초 동안 굽기 ×4 |
| 종료 / 기록 | 먼저 0이 된 쪽이 패배. 난이도별 **최단 승리 시간** TOP 5 (이겼을 때만) |
| 최대 길이 | 약 7분 (390초부터 급가속) |

### 변경 이력 (요약)
1. 불판 칸마다 키(1인당 12키) → 집게 2키(1인당 6키): 처음 하는 사람에게 너무 어려움
2. 집게 방식(6키) → **음식별 4키**: 키 안내 칸을 없애 화면을 식탁에 쓰기 위해
3. 경쟁 요소 추가: 같은 음식 먼저 집기 외에 상대와 부딪히는 지점이 없어서
4. 한 키보드 2인 대전 → **1인 vs CPU**: 한 키보드를 둘이 쓰기 어려워서. 검수용 봇을 CPU 상대로 재사용
5. 고기·버섯 키로 먹기까지 하던 방식 → **Shift + 칸 키로 먹을 칸을 직접 고름**: 혼자 하니 키보드 오른쪽이 비어서, 어느 칸을 먹을지 고르는 판단을 되살림

## ① 오브젝트 목록

### 음식 (공용 접시 4개, 접시 하나에 한 종류)
| 키 | 음식 | 처리 | 굽는 시간 | 단백질 | 탄수화물 | 비타민 | 보충 간격 |
|---|---|---|---|---|---|---|---|
| Q | 밥 | 바로 먹기 | – | 0 | +22 | 0 | 2.8초 |
| W | 고기 | 불판 | 4.5초 | +30 | 0 | 0 | 5초 |
| E | 버섯 | 불판 | 3초 | +5 | 0 | +22 | 5초 |
| R | 상추 | 바로 먹기 | – | 0 | 0 | +10 | 4.5초 |

- 접시당 최대 재고 3개, 시작 재고 3개.
- 바로 먹는 음식은 편하지만 양이 적거나 한 수치만 오른다. 많이 오르는 음식은 불판을 거쳐야 한다.

### 특수 음식 (경쟁 요소)
| 이름 | 어디에 | 언제 | 효과 |
|---|---|---|---|
| **황금 고기** | 고기 접시 맨 위 | 첫 등장 30~45초, 가져간 뒤 50~65초마다 | 굽는 데 6초. 먹으면 **세 수치 모두 +35**. 익으면 먼저 누른 사람이 임자 |
| **청양고추** | 상추 접시 맨 위 | 첫 등장 40~60초, 가져간 뒤 30~50초마다 | 먹은 사람 비타민 +5, **상대는 2초 동안 아무것도 못 먹음** (올리기는 가능) |

- 특수 음식은 일반 재고와 별도다. 접시에 남아 있는 동안은 다음 것이 나오지 않는다.
- 등장할 때 접시에서 반짝이며 "황금 고기 등장!" 같은 알림이 뜬다.

### 불판 (공용, 사각 철판에 8자리)
| 상태 | 조건 | 그 칸의 키(Shift+…)를 누르면 |
|---|---|---|
| 덜익음 | 굽는 시간 전 | 헛손질 (0.5초 잠김 + 세 수치 감소) |
| 익음 | 굽는 시간 뒤 4초 동안 | **누른 사람이 먹음** (나든 CPU든 먼저 누른 쪽) |
| ┗ PERFECT | 익은 뒤 **0.6초 안** | 영양 **1.5배**, 테두리가 노랑·흰색으로 빠르게 깜빡임 |
| 탐 | 익고 4초 뒤 | 헛손질. 2초 뒤 저절로 치워짐 |
| 빈 칸 | – | 헛손질 |

- 플레이어가 올린 음식은 왼쪽 위부터, CPU는 오른쪽 위부터 자리를 잡는다. 올린 사람 색 점이 표시되지만 소유권은 없다.

### 🔥 피버 타임
| 항목 | 값 |
|---|---|
| 첫 피버 | 60~100초 사이 무작위, 이후 끝나고 50~80초마다 |
| 지속 / 예고 | 8초 / 3초 전 예고 |
| 효과 | 굽기 ×4, 접시 보충 ×2 |
| 효과 없음 | 수치 감소, 익음→탐 4초 |

### 플레이어
| 항목 | 값 |
|---|---|
| 시작 수치 | 각 60 |
| 먹기 쿨다운 | 0.35초 |
| **헛손질** | 빈 접시·꽉 찬 불판·빈 칸·덜 익은 칸·탄 칸을 누르면 **0.5초 동안 아무 키도 안 먹힘** (연타 방지). 그중 **빈 접시·덜 익은 칸은 세 수치도 감소** — 쉬움 −3 · 보통 −5 · 어려움 −8 (나·CPU 같음) |

## ② 수치 규칙

```
감소량/초 = 1.0 + 0.012 × 경과초           (0초: 1.0/s, 180초: 3.2/s, 300초: 4.6/s)
390초 이후 추가 가속: + 0.08 × (경과초 − 390)
```
- 아무것도 안 하면 약 48초 만에 쓰러진다.
- 한 명의 수치 하나가 0이 되면 즉시 끝, 상대 승리. 같은 틱에 둘 다면 무승부.
- 결과 화면: 승자, 대결 시간, 패배 원인, 먹은 음식 수, PERFECT·황금 고기·고추 공격·뺏어먹기 횟수.
- 부스 랭킹: 가장 오래 이어진 대결 TOP 5 (localStorage), 이름 영문·숫자 3자.

## ③ CPU 상대와 시뮬레이션 봇 (`js/ai.js`)

### CPU 난이도
| 난이도 | 반응 시간 | 망설임(행동 건너뜀) | 황금 고기·고추 노림 | 헛손질 벌점 |
|---|---|---|---|---|
| 쉬움 | 0.6~0.9초 | 30% | X | −3 |
| 보통 | 0.4~0.6초 | 12% | O | −5 |
| 어려움 | 0.24~0.36초 | 0% | O | −8 |

사람 모델 vs CPU 100판 승률 (시뮬레이션):
| | 쉬움 | 보통 | 어려움 |
|---|---|---|---|
| 처음 하는 사람 (0.5~0.8초, 망설임 25%, 특수 음식 무시) | 84% | 2% | 0% |
| 보통 사람 (0.35~0.55초, 망설임 10%) | 100% | 69% | 6% |
| 잘하는 사람 (0.22~0.38초) | 100% | 100% | 61% |

### 봇 종류
- `idle`: 아무것도 안 함
- `random`: 4키 중 무작위 (연타 시험은 초당 약 14회)
- `greedy`: 익은 황금 고기·고추 최우선 → 부족한 수치에 맞는 익은 음식 → 바로 먹기 → 불판 채우기 (피버 예고 때 가득)
- `plain`: `greedy`와 같지만 황금 고기·고추를 일부러 노리지 않음

## ④ 조작 체계

```
Q  밥 먹기        Shift+Q W E R  →  불판 윗줄  1 2 3 4번 칸 먹기
W  고기 올리기    Shift+U I O P  →  불판 아랫줄 5 6 7 8번 칸 먹기
E  버섯 올리기
R  상추 먹기 (고추가 있으면 고추)
```
- 불판 칸 배치가 키보드 배치와 같다: 윗줄 = QWER 줄, 아랫줄 = UIOP 줄 (각 칸 아래에 ⇧키 표시, 먹을 수 있으면 노란색)
- CPU도 같은 규칙으로 칸을 골라 먹는다
- ⚠️ Windows에서 Shift를 5번 연달아 누르면 '고정 키' 창이 뜬다 → 부스 PC에서 바로 가기를 꺼 둔다
- 타이틀에서 **← →** 또는 **1 2 3** 으로 난이도 선택 (마지막 선택을 기억)
- **Space** 시작·다시 하기, **Esc** 일시정지, 타이틀에서 **T** 키 테스트
- `event.code`로 처리해 한/영 상태 무관, 키 반복 입력 무시

## ⑤ 화면 구성 (탑뷰 식탁, 640×360 논리 해상도를 정수배 확대)

```
┌──────────────────────── ⏱ 03:12 ────────────────────────┐
│ [나]        밥     고기    버섯    상추      [CPU 보통]  │
│ 단백질 ███  (접시) (접시) (접시) (접시)      단백질 ███  │
│ 탄수   ██     Q      W      E      R         탄수   ██   │
│ 비타민 ███ ┌──────────── 사각 불판 ────────────┐ 비타민 █ │
│            │  🥩    🍄    ✨🥩    🍄             │          │
│  ( 앞접시 )│  🍄    ·     ⚫     🥩             │( 앞접시 )│
│  젓가락·숟가락 └────────────────────────────────┘ 수저     │
│   (물컵)     김치 쌈장   [FEVER / 배고픔 속도]  마늘 파절이 (물컵) │
└──────────────────────────────────────────────────────────┘
```
- **자리(매트)**: 이름표, 수치 바 3개, 앞접시(마지막으로 먹은 음식이 쏙 커짐), 젓가락·숟가락, 물컵.
- **매운 상태**: 자리 전체가 붉게 맥동, 큰 고추와 "매워! 1.4" 카운트다운.
- **키 안내**: 접시 아래 빨간 키 칩(QWER), 불판 칸마다 ⇧키 칩(먹을 수 있으면 노란색). 별도 키 안내 칸 없음.
- **타이틀**: 로고, 3단계 그림 안내(접시 키 → Shift로 먹기 → 버티기), 난이도, 최단 승리 1~3위, `SPACE`. 자세한 규칙은 **H 도움말 화면**으로 분리.
- **결과**: 승리!/패배.../무승부!, 대결 시간, 나와 CPU의 기록.
- **불판**: 철판 테두리와 손잡이, 석쇠 틈으로 숯불. 진행 바, 올린 사람 색 점, 익음 테두리, 황금 고기 후광.
- **익음 표시**: 익은 음식은 모양을 따라 **노란** 빛 테두리(퍼펙트 구간은 흰색·주황 깜빡임)가 생기고, 그 칸의 ⇧키 칩만 노랗게 밝아진다.
- **가시성**: 나무결·숯·석쇠는 대비를 낮춰 음식이 도드라지게, 반찬은 2개만.
- **연출**: `+22`, `PERFECT!`, `뺏었다!`, `황금 고기!`, `고추 공격!`, `헛손질!` 문구가 떠오름. 헛손질 벌점은 게이지 옆에 빨간 `-8`.

## 남은 위험 요소
1. **PERFECT 0.6초는 봇 기준이다.** 사람에게 너무 어렵거나 쉬우면 `perfectWindow`만 바꾸면 된다.
2. **고추 2초 묶기가 짜증스러울 수 있다.** 실제 플레이에서 불만이 나오면 `chili.stun`을 1.5초로 줄인다.
3. **판 길이**: 봇 기준 평균 약 5분 40초. 사람끼리는 실력 차로 더 빨리 끝날 것으로 보지만, 줄이 길면 `rampStart`(390초)를 줄인다.
4. **CPU 난이도는 사람 모델(반응 시간 가정) 기준이다.** 실제 손님 승률이 너무 높거나 낮으면 `DIFFICULTY`의 반응 시간·망설임만 조정한다.
