# progress — 불판 대첩 검수 로그

## 검수 1회차 (self-check)

### 1단계 — 완료 기준 ↔ 테스트 대조
- 기획서 ⑥ 완료 기준은 모두 테스트에 1:1로 대응돼 있었다.
- 빠진 곳 7개를 찾아 테스트를 추가했다:
  1. 상태를 건드리지 않는 통째 플레이 (부팅→시작→실제 경기→결과)
  2. 긴 경기 동안 매 틱 불변 조건 (수치 0~100, 재고 0~3, 불판 상태, NaN 없음)
  3. 함정 A(교착) 대응: 불판 8칸이 꽉 차도 아무도 안 먹으면 결국 모두 비워지는가
  4. 함정 B(헛돌기) 대응: CPU가 헛손질을 반복하며 맴돌지 않는가
  5. 무승부 결과 화면
  6. 카운트다운 중 ESC / 일시정지 중 BACKSPACE로 타이틀 복귀
  7. 브라우저 저장소(localStorage) 접근이 막힌 환경

### 2단계 — 실제 실행
- headless: 난이도 3 × 시드 3 = 9경기를 1/60초 단위로 끝까지 돌리며 매 틱 불변 조건 검사 → 위반 0건, 전부 450초 안에 종료.
- 검사 자체 검증: 수치를 0으로 막는 줄을 일부러 지우자 267.5초에 "carb=-0.04" 위반을 잡아냄 → 되돌림.
- CPU 헛손질 비율: 6경기 기준 3% 미만 (헛돌기 없음).
- 브라우저(Chromium): 사람처럼 실제 키를 눌러 20초 플레이 + 모든 화면 순회 (타이틀·도움말·키 테스트·카운트다운·게임·일시정지·승리·패배) → 콘솔 에러·경고 0건.

### 4단계 — 실패 → 원인 → 수정
- [고침] 저장소가 막힌 브라우저(쿠키 차단, 일부 사생활 보호 모드)에서 게임이 아예 켜지지 않음.
  원인: ranking.js가 localStorage를 함수 기본 매개변수(`storage = globalThis.localStorage`)로 꺼내서,
  접근 예외가 try 바깥에서 터지고 main.js 모듈 전체가 멈췄다.
  → 저장소를 try 안에서 꺼내도록 수정. 옛 코드에선 실패하고 새 코드에선 통과하는 단위 테스트를 추가.
- [고침] 타이틀 "SPACE 로 시작"과 결과 "SPACE 다시 하기"가 깜빡일 때 아예 사라져, 절반의 시간 동안 다음에 누를 키가 안 보임.
  → 사라지지 않고 흰색↔노란색으로만 바뀌게 수정.
- 재실행: npm test 46/46, 브라우저 26/26 통과.
